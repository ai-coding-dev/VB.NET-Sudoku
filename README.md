# Sudoku Game (VB.NET)

A simple and elegant 9x9 Sudoku game built using Visual Basic .NET and Windows Forms. It features dynamic grid generation, a backtracking algorithm for puzzle creation, and real-time solution validation.

## Features
* **Dynamic UI**: 9x9 grid with visual distinction for 3x3 subgrids.
* **Random Generation**: Each game is unique, powered by a backtracking algorithm.
* **Validation**: Real-time feedback with color coding (Red for errors, Blue for correct entries).
* **Input Control**: Restricts input to numbers 1-9 only.

## How to Run
1. Open Visual Studio.
2. Create a new **Windows Forms App** project.
3. Replace the code in your main form or `Program.vb` with the provided source code.
4. Press `F5` to build and run.

# 数独游戏 (VB.NET)

这是一个使用 Visual Basic .NET 和 Windows Forms 开发的 9x9 数独游戏。它具有动态界面生成、基于回溯算法的任务生成以及实时解法校验功能。

## 功能特点
* **动态界面**：自动生成 9x9 网格，并对 3x3 宫格进行视觉区分。
* **随机生成**：利用回溯算法确保每次点击“新游戏”都会生成一个唯一且有效的数独题目。
* **解法校验**：提供实时反馈（错误显示为红色，正确显示为蓝色）。
* **输入限制**：严格限制用户仅能输入数字 1-9。

## 如何运行
1. 打开 Visual Studio。
2. 新建一个 **Windows Forms App** 项目。
3. 将提供的源代码覆盖到主窗体文件或 `Program.vb` 中。
4. 按下 `F5` 进行编译并运行。

# 数独ゲーム (VB.NET)

Visual Basic .NET と Windows Forms を使用して作成された、シンプルで洗練された 9x9 の数独ゲームです。動的なグリッド生成、バックトラッキングアルゴリズムによる問題作成、およびリアルタイムの答え合わせ機能を備えています。

## 特徴
* **動的 UI**: 9x9 のグリッドを表示し、3x3 のブロックごとに背景色を色分けして視認性を高めています。
* **ランダム生成**: バックトラッキングアルゴリズムにより、実行するたびに異なるパズルが生成されます。
* **答え合わせ**: プレイヤーの入力が正しいかチェックし、エラーを赤色、正解を青色で表示します。
* **入力制限**: 1から9までの数字のみが入力できるように制限されています。

## 実行方法
1. Visual Studio を開きます。
2. 新しい **Windows フォーム アプリ** プロジェクトを作成します。
3. 提供されたソースコードをメインフォームまたは `Program.vb` に貼り付けます。
4. `F5` キーを押してビルドおよび実行します。
